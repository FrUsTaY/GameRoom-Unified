# GameRoom

**GameRoom** — это Android-приложение для управления коллекцией видеоигр, созданное с использованием гибридной архитектуры (WebView + React). Приложение позволяет вести учет пройденных игр, составлять список желаемого (wishlist) и получать расширенную информацию об играх, включая интеграцию с внешними сервисами и поддержку офлайн-режима.

## 🚀 Ключевые возможности

### 🎮 Управление коллекцией
- **Добавление игр:** Возможность поиска и добавления игр через API RAWG или вручную.
- **Списки:** Разделение игр на списки (пройденные, играю сейчас, вишлист).
- **Редактирование:** Настройка информации об игре, выставление оценок и статуса.

### 🌐 Интеграции
- **RAWG API:** Поиск игр, получение обложек и базовой информации.
- **GigaChat API и Gemini:** Получение AI-инсайтов и рекомендаций по играм (в приложении реализован переключатель ИИ-помощника — Хранителя).
- **YouTube:** Просмотр трейлеров игр.
- **Яндекс.Диск:** Синхронизация и резервное копирование данных пользователя.

### 📡 Офлайн-режим (Автономность)
Приложение полностью функционально без доступа к интернету:
- Загрузка приложения и отображение локальных списков.
- Кэширование данных (LocalStorage, IndexedDB) и обложек игр.
- Встроенные индикаторы статуса сети (`ONLINE`, `PARTIAL`, `OFFLINE`).

## 🛠 Стек технологий

### Мобильная часть (Android)
- **Язык:** Kotlin
- **Компоненты:** WebView (для отображения интерфейса), Service Worker.
- **Система сборки:** Gradle.

### Frontend часть (Встроенная)
- **Библиотеки:** React (без JSX компиляции на лету), ReactDOM, Babel (для старых устройств), Tailwind CSS, Lucide (иконки), Chart.js (статистика).
- **Хранение данных:**
  - `LocalStorage`: для малых данных (списки игр, настройки, кэш API).
  - `IndexedDB`: для больших данных (обложки игр как blobs, долгосрочный кэш).
  - `Cache API (Service Worker)`: для кэширования локальных библиотек, CSS и шрифтов.

## 🏗 Архитектура

Приложение использует локальный веб-сервер / загрузку локальных файлов (`file:///android_asset/GameRoom.html`). Вся логика работы интерфейса находится внутри папки `app/src/main/assets/`.

```text
GameRoom/
├── app/src/main/
│   ├── java/                # Код Android (Kotlin)
│   ├── res/                 # Ресурсы Android (Иконки, манифест)
│   └── assets/              # Веб-приложение (Frontend)
│       ├── GameRoom.html    # Входная точка
│       ├── lib/             # Локальные JS-библиотеки (React, Tailwind и др.)
│       ├── js/              # Логика React-приложения
│       ├── css/             # Стили
│       └── fonts/           # Локальные шрифты (Jura, Russo One)
```

## ⚙️ Инструкция по сборке и запуску

1. **Клонирование репозитория:**
   ```bash
   git clone <URL_репозитория>
   cd GameRoom
   ```

2. **Открытие проекта:**
   - Откройте проект в **Android Studio**.
   - Дождитесь синхронизации Gradle.

3. **Настройка API-ключей (если требуется):**
   - Убедитесь, что у вас есть ключи для RAWG API, а также GigaChat API или Gemini API, если планируете тестировать онлайн-функции.

4. **Запуск:**
   - Подключите Android-устройство или запустите эмулятор.
   - Нажмите `Run` (или `Shift + F10`) в Android Studio.

## 🔌 Тестирование офлайн-режима

Приложение специально адаптировано для работы без интернета:
1. Запустите приложение.
2. Отключите Wi-Fi / Мобильные данные (включите режим "В самолете").
3. Приложение продолжит работать:
   - В хедере появится статус `OFFLINE` 📡.
   - Будут доступны списки игр, вишлист и пройденные.
   - Кнопки поиска RAWG, AI-инсайтов и трейлеров будут отключены с пометкой "Требуется интернет".
